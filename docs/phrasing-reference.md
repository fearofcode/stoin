# Phrasing Reference

## Phrase layer

| Phrase type | Marker | Stroke shape |
| --- | --- | --- |
| Initial verb (IV) | ∅ | IV stem + IV form + shared tail |
| Final verb (FV) | U | U + shared starter + FV operator + FV structure + FV ender |
| Nonverb (NV) | E | E + shared starter + shared tail |
